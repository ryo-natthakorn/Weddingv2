# Wedding E-Card — ปัญหาที่ยังไม่ได้แก้ (open issues)

ไฟล์หลัก: `Wedding E-Card.dc.html`
สถานะ: แกลเลอรีถูก revert กลับเป็นวงโคจรแบบเดิมทั้งหมด (ไม่มีปุ่มลูกศร / ไม่มีข้อความบอกวิธีเล่น / ทุกรูปกดได้)

## 1. ขอบสแตมป์กระตุกตอนรูปสลับชั้น
รูปที่หมุนเข้ามาจากซ้ายจะ "เด้ง" ขึ้นมาทับขอบสแตมป์ด้านซ้ายของรูปหน้าสุดแบบไม่ลื่นไหล

- สาเหตุ: `layoutOrbit()` กำหนด `zIndex` จากค่าความลึก `z = cos(a) * radius` รูปสองใบที่ขนาบจุดกลางหน้ามี `z` เท่ากันพอดีตอนผ่านกลาง จึงสลับลำดับชั้นทันทีใน 1 เฟรม
- ตอนนั้นรูปสองใบทับกันประมาณ 40–50% ของความกว้าง (บนมือถือ `card ≈ 2 × radius`) การสลับจึงเห็นชัด
- แนวทางที่ลองแล้วได้ผลแต่ผู้ใช้ไม่ชอบหน้าตา: กางมุมรูปให้ห่างกันเมื่อเข้าใกล้ด้านหน้า (`a = a + fan * sin(a)`) ทำให้จุดสลับเกิดตอนแทบไม่ทับกัน แต่วงดูโปร่ง/กระจายเกินไป
- แนวทางอื่นที่ยังไม่ได้ลอง: ลดขนาดรูปหรือเพิ่มรัศมีเล็กน้อยเฉพาะมือถือ / ครอสเฟดช่วงสลับ / ลดคอนทราสต์ขอบสแตมป์ของรูปที่อยู่ถัดจากหน้าสุด

## 2. กดโดนรูปด้านหลังโดยไม่ตั้งใจ
ทุกรูปในวงเป็น `<button>` ที่กดได้ จึงเผลอเปิดรูปหลังบ่อย

- แนวทาง: หา index ที่มุมใกล้ 0 ที่สุดในแต่ละเฟรม แล้วตั้ง `pointerEvents: "auto"` เฉพาะใบนั้น (ใบอื่น `"none"`, `tabIndex = -1`) และกันซ้ำใน `openZoom(i)` ด้วย — ทำแล้วใช้งานได้ดี แต่ถูก revert รวมไปกับข้ออื่น สามารถหยิบกลับมาเฉพาะข้อนี้ได้

## 3. ไม่มีตัวบอกวิธีเล่นบนมือถือ
ผู้ใช้ครั้งแรกอาจไม่รู้ว่าต้องลากเพื่อหมุน และแตะเพื่อดูเต็มจอ ยังไม่มี hint / onboarding ใด ๆ

## 4. ใช้งานยากบนคอมพิวเตอร์
มีแต่การลากด้วยเมาส์ ไม่มีปุ่มลูกศร ไม่มีคีย์บอร์ด ไม่มี snap ทีละรูป และวงหมุนอัตโนมัติตลอดจนเล็งกดยาก (auto-rotate หยุดเฉพาะตอน hover)

## 5. Intro
การแก้ครั้งล่าสุด (ครั้งเดียว) คือแก้บั๊กโลโก้ PN ทับสไลเดอร์แหวนตอนจอสูงน้อยกว่า ~676px โดยเปลี่ยนเป็น flex column + ระยะแบบ `clamp()` — ยังไม่ได้ revert เพราะการย้อนกลับจะทำให้บั๊กทับซ้อนกลับมา ถ้าต้องการย้อนจริงให้แจ้ง
